# EL Records — The Abyss Rises

A responsive, static landing page concept for EL Records.

## Preview locally
Open `index.html` in a browser.

## Publish
This folder can be uploaded to a GitHub repository and published with GitHub Pages, or deployed to Cloudflare Pages / Netlify.

## Before launch
- Replace placeholder release status and artwork with approved assets.
- Add official album / streaming links.
- Add download files only after confirming the required distribution and download rights.
- Replace generic social link with the official EL Records profile.
- Confirm business/legal imprint details before public launch.

No build step required.
